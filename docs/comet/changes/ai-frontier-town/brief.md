# Outcome

实现独立、自托管优先的 AI 沙海小镇：晨沙镇的 20 位居民自主生活、对话与记忆；镇长提案受自治章程和真实财政/物资/自愿劳动约束；规划蓝图经过讨论、批准、施工才成为真实建筑，世界可持久恢复。

# Scope

覆盖用户指定的整份 v2.0 文档，不缩减为 23.1 的 M0 示例。依次完成 M0 世界骨架、M1 居民、M2 模型/社交记忆、M3 经济、M4 治理、M5 施工可玩 MVP，再 M6 环境社会、M7 可选 Jev 与治理深化、M8 扩张移民、M9 最小长线演化。每阶段必须验收通过再进入下一阶段，报告保存至 docs/reports/Mx-IMPLEMENTATION-REPORT.md。

# Non-goals

不依赖既有 OA/ERP 或其他小镇仓库；不做多人实时联机、MMO、微服务/Kubernetes、复杂资本市场、无限居民/地图。明确标为远景的地价/产权完整市场、保险/复杂信贷等不属于本轮必交付。正式选举与章程调整保留原文玩法成熟条件，未满足时不得伪造完成。未经授权不发布、推送、合并、清理工作区，不做破坏性数据库操作，不再分发未授权素材。

# Acceptance examples

- M0：pnpm/TypeScript monorepo 可按 README 启动；Vue 3 + Phaser 3 显示数据驱动的晨沙镇沙漠地图，支持拖动、缩放、点选建筑与角色；Fastify + PostgreSQL + Drizzle 迁移、最小 HTTP/WS 鉴权、世界创建/加载、暂停/恢复/1×2×4×与快照可用；两个 Worker 竞争时无重复 Tick，重启恢复地图与游戏时间。
- M1：20 位原文命名居民的独立 JSON 档案具备 100–300 字背景、五维人格、技能、价值观、需求、资产、目标、住所与有向关系；无 LLM 连续模拟至少 3 天，作息、饮食、工作、昼夜与动态寻路可观察，无穿墙、瞬移、双重占用或长期死锁。
- M2 模型中心：可配置远程/本地 OpenAI-compatible 供应商和协议适配接口，按用途及居民覆盖模型策略、安全保存/更换/停用密钥、测试连接、用量/费用/错误/延迟、预算与备用模型；真实兼容测试服务能切换；401/429/超时/断网/预算耗尽均回退，不阻塞 Tick。
- M2 居民自治：至少两对居民主动邀请、接受/拒绝、逐句对话、结束并恢复日程；最大回合/时间/令牌限制与会话互斥有效；结构化人格、个人状态、独立记忆检索和目标构建上下文；新目标仅映射合法有限动作，未知行动保留为愿望。
- M2 记忆与知识：个人记忆按来源、隐私、可信度、转述深度、重要性保存并检索，关系有向更新；A→B 私密对话不进入 C 上下文/镇长视图，B 三天后可回忆修井帮助，未履行的公开承诺影响医生支持；传闻不变成事实，重启保持来源与可见性。
- M3：水/粮/木/石/工具/住房/耐久/工时按配置结算，水塔只增加容量、农田实际耗水；公私账户分离、原子平衡流水、预留与可用余额、薪资/基础消费/贸易/自愿任务可核算；10 天生产消费账实一致，失败和重试无负库存、重复扣款或重复承诺，财政库存看板提示缺水。
